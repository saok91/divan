## What went well

- **Epic 6 prep encodes paid off:** Migration-evidence honesty and consume-6.5 artifact contracts landed in 7.1 Gates before code; 7.3 hold-gated `disposeExportArtifact` without a parallel byte SoT.
- **7.1 pattern template scaled:** envelope domain + seed + thin governed tRPC + Layout≠RSC + GovernedDataTable + operational-copy + soft-deny secondary — reused across 7.2–7.8.
- **Product distinction tables prevented SoT sprawl:** FR-17 vs FR-53 (7.5); run / export / publication (7.6); four-way Launch Artifact vs recon waiver vs publication vs export (7.7); five-path evaluation snapshot matrix (7.8).
- **Honesty culture held under pressure:** AD-6 orphans / events-only zero-trace banners; PopulationPort fixture disclosure; AR register seeded `pending`/`partial_freeze`; backup not-configured; disposal never blocked solely for reproducibility.
- **Required vs secondary audit table (7.4)** became the epic-wide invariant for soft-deny vs fail-closed mutations.
- **Cross-story handoffs were explicit:** disposal_run → 7.5/7.6; `pending_publication_hook` → 7.6; provisional versions → 7.7 controlling resolver; shared hash → 7.8; 6.4 waiver helpers shared with 7.7.
- **IA restraint:** retention under dictionary Admin; publications from reports catalogue; Launch Artifacts / snapshot honesty under ops — few invented routes.
- **Immutability defense-in-depth:** DELETE-forbid / append-only triggers on lifecycle, publications, and snapshot registry tables.
- **AR fail-closed held:** eleven AR ids registered honestly; no invented freeze numbers for AR-AUDIT / AR-ACCESS / AR-DATA / AR-NFR / AR-MIGRATION.

## Challenges

- **Integration stories absorbed the heaviest review load:** 7.7 (~25 patches) and 7.8 (enforcement gaps: UI not consuming server pagination token, bind fail-open, mid-flight revalidate no-ops) cost more than greenfield panels 7.1–7.2.
- **Fail-open consumer hooks recurred:** bare catch on publication gates (7.7), soft-swallow required append after persist (7.4/7.5), bind “success” with zero rows (7.8) — “hook present” ≠ “enforced.”
- **UI completeness lagged API:** 7.5 preview/evidence refs; 7.7 waiver close / conflict resolve; 7.8 manage expire/supersede and pagination token — recurring DoD gap.
- **Provisional SoD on `hr.admin`:** manage + approve + publish + supersede on one PermissionSet across 7.5–7.8; independent-approver attestation remains free-text depth.
- **org:selfcheck / unscoped list IDOR class** deferred again (7.3 holds, 7.5 cases, 7.6 publications).
- **Selfcheck ceiling mostly unchanged:** helper / source-grep oracles; Postgres often skipped; full unauthorized tRPC smoke and live LDAP→red still thin.
- **BOM on `sprint-status.yaml` (Windows)** recurred in 7.1 / 7.2 / 7.4 reviews — habit, not tooling.
- **Carry-ins untouched again:** AD-6 single-connection; Baseline→Employment/Assignment projector; PopulationPort cutover; person-org mutation IDOR; person-create form dedupe; logout leave-guard; Vitest/ephemeral isolation; hash-chain tamper evidence; export Base64 streaming.

## Key insights

1. **Consumer/integration stories need an “enforcement matrix” DoD** — substrate + router + UI consumption + mid-flight revalidate + status guards, not “wired” alone (7.7 / 7.8).
2. **Product distinction tables are cheaper than parallel SoTs** — naming collisions (`health`, Correction, publication vs Launch Artifact) are predictable; Gate them early.
3. **Fail-open after allow-path persist is a security near-miss class** — required append and gate asserts must share the mutation TX or hard-fail the write.
4. **Honesty banners + Absolute non-goals scale better than inventing green** — operators get usable substrate without false LG / AR completeness claims.
5. **Cross-story consume contracts work when named in prior retro** — Epic 6 #2/#3 closed visibly in 7.1/7.3; unpaid technical carry-ins did not block delivery but still undermine production-completeness narratives.
6. **MVP closeout ≠ production freeze** — FR42–FR56 substrate done; AR-ACCESS SoD, list scoping, PopulationPort, AD-6, and hash-chain remain launch-gate honesty items.
