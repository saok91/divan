## What went well

- **Epic 5 prep encodes paid off:** PopulationPort honesty, Import Batch never-fabricate, and export reauth/custody notes landed in 6.1 / 6.5 Gates before code — fewer rediscoveries on those themes.
- **Confirm ≠ execute held (AD-4):** 6.1 froze drafts only; production ingress is exclusively 6.2 staging → atomic cutover after independent approval.
- **Honesty culture scaled to migration gates:** unavailable ≠ invent `{ count: 0 }`; free-string tokens cannot unlock production; rubber-stamp controls rejected in 6.4 review; export omit stays fail-closed without seeded `*.export`.
- **Evidence-backed report activation:** `import_batch_outcomes` stayed unavailable until cutover-complete evidence existed — closes Epic 5 stub boundary without greenwash.
- **First production consumer of artifact reauth:** 6.5 calls `reauthorizeForQueuedOrArtifactWork` on create and download — closes Epic 2 consumer mandate and Epic 5 “encode into 6.5” action.
- **Provenance as read model, not control plane:** 6.3 distinguished Baseline/imported/native without rewriting cutover; `source=migration` remains audit metadata only.
- **Domain-in-package discipline:** `@divan/migration` owns parse/validate/staging/reconcile; `@divan/reporting` owns export artifacts; thin governed tRPC in `apps/web`.
- **Leave-guard data-state habit:** dirty ≠ Sheet/dialog open carried from 4b/5 into import preview, staging, and reconciliation forms.
- **Cross-story learning transfer:** 6.5 explicitly avoided 6.4 pitfalls (action/read meta mismatch, invent zeros, BOM, rubber-stamp).

## Challenges

- **6.4 gate correctness absorbed the heaviest review load:** ~20 patches covering unavailable-domain hard-block (even with FR-55 waiver posture), waiver expiry, tier must be `production-candidate`, stale hash, concurrent dual-sign race, permission action mismatch, leave-guard over-dirty.
- **AD-6 honesty gap remains unpaid:** `createPerson` on Prisma outside PoolClient cutover TX can leave Person orphans while Baseline events roll back; `assertZeroProductionTrace` is events-only — accepted as Absolute non-goal, still real for ops/audit integrity narratives.
- **No PE projector for `BaselineRecorded` → Employment/Assignment:** recon domains stay honestly `unavailable`; production cutover hard-blocked until observation is computable or AR oracle exists — correct product posture, incomplete projection spine.
- **Selfcheck ceiling unchanged:** helper/`tsx` oracles; Postgres `:5433` often refused → DB smoke skipped; weak concurrent/orphan/full create→sign→execute coverage.
- **PopulationPort still fixture-default:** honesty fields present; actual default-registry cutover still open since Epic 3–5 — migration must not claim production workforce authz.
- **Carry-ins untouched again:** person-org mutation IDOR (Cancel/Reverse/Correct); person-create form dedupe; logout → `requestNavigation` leave-guard; Vitest/ephemeral isolation; AD-6 hardening; `ensure*Schema` migrations-only.
- **UTF-8 BOM on sprint-status:** recurred; patched in 6.4 review — still habit, not tooling.
- **Scale deferrals:** 5k-row preview payload, Excel rate-limit/zip-bomb, 32-bit FNV advisory hash collisions, Base64-in-tRPC export download without size cap/streaming.

## Key insights

1. **Gate stories need adversarial budget up front** — 6.4 (production unlock) was harder than 6.2 (TX spine) because client-token and waiver edge cases are security near-misses, not just logic bugs.
2. **Honesty beats provisional green** — hard-blocking production on `unavailable` domains is better than inventing zeros that would lie about Employment/Assignment fidelity.
3. **Events-only “zero production trace” understates orphan risk** — AD-6 split Prisma/PoolClient makes “clean rollback” claims incomplete; investigation UX must not treat events-only zero-trace as full integrity proof.
4. **Cross-story pitfall notes work** — encoding 6.4 failures into 6.5 Dev Notes prevented repeating action-meta and invent-zero defects.
5. **Stub → evidence activation is a product invariant** — report keys and export affordances stay unavailable until real evidence exists; naming the successor story prevents false “done.”
6. **Provenance UX is not cutover control** — presentation stories must refuse to become a second control plane; pagination incompleteness can still falsify boundary claims.
7. **Consumer epics still succeed when Gates encode prior retro debt** — Epic 5 actions #2–#4 completed into 6.1/6.5 and visibly shaped Decisions.
