### Delivery narrative

Greenfield modular-monolith substrate → brand/theme → app shell → seeded auth → role landings/nav → command palette / Jalali / Persian digits → a11y floor & banners → LDAP (infra-gated). Code review + patch applied on essentially every story. Deferred-work loop closed many 1.2/1.3 items in 1.5/1.7.

## What went well

- Clear architecture seed (AD-1/3/5/6) and explicit non-goals per story kept scope from ballooning.
- Seeded vs LDAP separation without inventing topology; fail-closed auth patterns held.
- Deferred-work.md stayed alive: debts tracked, many resolved in later Epic 1 stories.
- Cross-story lessons carried (e.g. never import `@divan/identity-access` from client — pulls `pg`).
- Persian RTL desktop shell, brand tokens, operational copy catalog, and a11y floor reached a coherent baseline.
- Strong adversarial code-review habit produced actionable patches before marking done.

## Challenges

- Accessibility / RTL / focus patterns surfaced late in review across multiple stories (1.2, 1.3, 1.6, 1.7) rather than as front-loaded DoD.
- Selfcheck scripts (navigation, jalali/persian, ldap-auth, a11y-floor) not wired into package scripts/CI — manual `tsx` only.
- JWT / session staleness: coarse role and LDAP directory state can lag after demote/disable until refresh or re-login.
- Layout-only path gate swaps UI but does not stop forbidden `page.tsx` RSC execution — safe for empty shells, unsafe once loaders exist.
- AR-IDENTITY still open (topology, group→role, bind account-state codes, STARTTLS) — entitlements work must not assume frozen directory sync.
- Process hygiene: occasional `next-env.d.ts` path drift; story-file Status vs sprint-status drift.

## Key insights

1. Review quality is high; more a11y and authz boundary criteria should move into create-story / DoD so patches are fewer and earlier.
2. Epic 1 bootstrap succeeded; Epic 2 default-deny must not trust UI visibility or layout gates alone.
3. Thin FR42 substrates (`AuthAttempt`, `AccessDenial`) must migrate into real audit-envelope rather than accumulate parallel write paths.
4. Closing deferred items inside the same epic worked — keep that habit for Epic 2.
