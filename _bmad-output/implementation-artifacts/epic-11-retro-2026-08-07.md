## Challenges

- **Presentation honesty bugs clustered:** invented ops path; conflicts dropped at tRPC; scavenger-hunt activate; failure-tone empty on expected-empty Start.
- **Session-loading / pendingIntent races:** SysAdmin flash as non-ops (11.1); Override flash (11.2); dual-CTA re-submit gap between create and activate (11.6).

- **a11y naming / focus / describedby** still review-heavy (11.1 focus ring; 11.3 aria-controls; 11.4 icon-in-label; 11.7 emptyCopyFa masking filtered empty).
- **Behavioral selfchecks still thin** where source gates + manual DoD substituted (stale→reclaim→clear; dual-mutation races caught in review).
- **Epic 10 production-honesty carry-ins intentionally unpaid** — correctly out of Epic 11 scope, still blocking LG-complete claims.

## Key insights

1. **UAT dead-ends are often honesty/transport bugs, not missing domain features** — reclaim set mismatch, dropped `conflicts[]`, unsaved preferred capacity, invented menu paths.
2. **Role-honest next steps must point at real destinations** — invented IA is worse than “contact SysAdmin.”
3. **Reject transport integrity equals gate integrity** — domain richness is useless if tRPC strips it.
4. **Prop-scoped empty taxonomy beats global tone changes** — expected-empty must not poison search-miss or Terminate-required Employment.
5. **Glossary selfchecks must lock concrete keys** — raising a ceiling without asserting new keys is a false green.
6. **Client dual-mutation UX needs pendingIntent across the gap** — invalidate failures must not masquerade as create failures; FR-28 still forbids client-faked Active.
7. **Closing UAT friction ≠ closing the honesty ledger** — Epic 11 restores operable flows; Epic 7–10 production/LG debts remain open by design.
