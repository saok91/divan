### Delivery narrative

Audit-envelope + default-deny (2.1) → sensitive category omit + export segregation (2.2) → access administration UI/APIs (2.3) → entitlement lifecycle + lazy fail-safe (2.4) → break-glass elevation (2.5) → temporal/cross-boundary PopulationPort control plane (2.6) → inference/bulk InferenceBulkPort control plane (2.7). Adversarial code review + patch on essentially every story. Deferred-work loop closed many Epic 1 / early-2 items inside later stories of the same epic.

## What went well

- **AD-5 made real:** Coarse identity-access context + fine envelope category checks + append-only `event_class=access` became the shared control plane for all governed paths.
- **Epic 1 retro commitments largely landed:** Layout≠RSC encoded in 2.1; DB freshness on governed entry; FR42 migration plan (stop sprawl); a11y DoD on interactive 2.4; package `selfcheck:audit-envelope`; no invented LDAP group→role.
- **Control-plane-before-domain pattern:** Stories 2.6/2.7 shipped `PopulationPort` / `InferenceBulkPort` with fixtures and shared channel semantics so Epic 3/5/6 can consume without reinventing authz.
- **Fail-closed vs invent:** AR-ACCESS / AR-DATA / AR-REPORTING / AR-IDENTITY left open with configurable hooks and demo numbers gated — production values not invented.
- **Break-glass discipline:** Elevation does not bypass temporal intersection or inference/bulk (closed across 2.5→2.6→2.7); export/admin remain deniable by default.
- **Deferred-work hygiene:** Same-epic debt closure continued (e.g. forever-live break-glass mock fixed in 2.5; temporal/inference deferrals marked done when control planes shipped).
- **Evidence compensate pattern:** Evidence failure → compensate + fail closed reused from 2.3 onward (FR-51).

## Challenges

- **JWT / shell staleness remains:** RSC shells can still render for inactive JWT; governed tRPC fails closed. Full Auth.js revoke / continuous LDAP revalidation still open (AR-IDENTITY / ops).
- **Selfcheck depth uneven:** Package scripts improved for envelope path; many governed selfchecks still thin demos (omit/export wiring, category registry paths) — Vitest/CI still not a story.
- **Lifecycle vs legacy bindings:** Standard single-assign / empty wipe paths and non-grant joins sit outside full expiry/recert fail-safes; mass_assignment gated but multi-target fulfillment deferred.
- **Client/session edge cases:** Sticky `breakGlassOverride`; fingerprint ignores permission-set content mutations on same role ids; mid-session AUTHZ_CHANGED incomplete for privileged permission edits.
- **Inference window store is process-local:** In-memory `actorWindows` races and multi-instance bypass until shared store under AR-ACCESS — acceptable under AD-1 single process MVP, dangerous if ops assumptions change.
- **Process hygiene carry-over:** Epic 1 action “align story-file Status with sprint-status” still open; `epic-2` stayed `in-progress` after all stories were `done`.

## Key insights

1. **Ports as contracts beat premature domain wiring** — fixture Population/Inference planes let authz semantics harden before Person/Org projections exist.
2. **Elevation must compose with every control plane** — break-glass that skips temporal or bulk thresholds is a product bug, not a feature; 2.6/2.7 closed that class of deferral.
3. **Same-epic deferred closure works** — keep resolving review deferrals in later stories of the epic rather than banking them only for future epics.
4. **Epic 3 risk is sequencing, not authz substrate** — temporary CRUD write paths would violate the Epic 3↔4 rule and create throwaway code; master-data must stay read/invariant-first.
5. **Open AR artifacts are a feature gate, not a backlog excuse** — fail-closed hooks with pending numbers are correct; inventing thresholds or group→role sync is not.
