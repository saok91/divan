## What went well

- **Authoritative mutation path landed:** Append-only business events + Draft working store + AD-6 same-txn projection hook became the only product mutation surface for workforce state.
- **Neutralization as law (4.3):** Cancel/Reverse/Correction append new rows; resolved display status ≠ storage rewrite — unlocked honest history for 4.9–4.11 and timeline consumers.
- **Transfer coverage handoff closed (4.7):** Epic 3 / 4.1 prep (“coverage **after** atomic close+open”) shipped; evaluation-by-date apply fixed UJ-1 storage-Scheduled gap.
- **Read products compose, not invent SoT (4.9–4.11):** Shared as-of helpers, planned future (facts @ today), and event-linked headcount ledger separated live counters from historical truth.
- **Headcount product stack closed (4.12–4.14):** Approval ceiling → Approval-first match → exemptions ≠ Override → durable Start reserve + Override negative free + Scheduled-exception — FR-28–32 coherent end-to-end.
- **Sensitive compensation channel (4.8):** Sidecar satisfied evidence denylist without putting amounts in draft/event payloads.
- **Carry-in intelligence worked:** Later Operators re-used noon-UTC DATE hygiene, ALS hooks, compensate patterns, scoped fixtures, Gate/non-goals tables — review still tightened, but fewer first-principles rediscoveries than Epic 3 early stories.
- **Epic 3 prep largely applied:** Transfer sequencing encoded and implemented; PopulationPort cutover **criteria** written; seed/BOM DoD present (BOM still recurred as process tax — see Challenges).

## Challenges

- **AD-6 Prisma vs PoolClient split:** Projector writers on Prisma/`getPersonDb()` while finalize append runs on `PoolClient` — compensate paths grew story-by-story (4.5–4.8); single-connection hardening still open (High).
- **IDOR / unscoped list-get:** Permission-only list/get on drafts, sidecars, Approvals, exemptions, Overrides — flagged every headcount/personnel story as “pre-existing”; Epic 5.1 cannot claim permission-safe search without addressing scope.
- **Shared-DB selfcheck pollution:** Sequential `tsx` selfchecks + shared seed Teams caused false counts, drained slots, and worker job backlog; Vitest/ephemeral isolation still deferred from Epic 3.
- **UTF-8 BOM on sprint-status:** Recurred across multiple Done transitions despite Epic 3 DoD — process habit not yet automatic.
- **Idempotent finalize / compensate flag accuracy:** Early-return finalized drafts can skip projection hook (orphan heal gap, 4.6); `didClose*` / `didMove*` false positives on idempotent hits (4.6–4.8).
- **PopulationPort still fixture-backed by default:** Criteria exist; default registry cutover not executed — Epic 5 authz population paths must not assume real workforce membership.
- **ensure\*Schema DDL on every tRPC request:** Approval / exemption / Override helpers run DDL per request — migrations-only runtime still deferred.
- **AR matrices remain open:** AR-TEMPORAL / AR-HEADCOUNT / AR-DATA / AR-ACCESS fail-closed stubs continued correctly; orphan disposition beyond Override/Cancel/Correction still not invented (good) but formal freeze still pending.

## Key insights

1. **Substrate → Operators → Reads → Headcount governance is the right epic shape** — complexity spiked where atomicity + concurrency + lifecycle met (4.7, 4.13, 4.14); read stories were safer because they composed existing helpers.
2. **Evaluation-by-date is mandatory for Scheduled storage** — treating storage status alone as apply truth breaks Transfer and headcount; `evaluationStatusAsOf` is a product contract, not a helper detail.
3. **Fail-closed beats silent floors** — Override negative free and Scheduled-exception made shortages visible; silent `free >= 0` floors would have lied to operators.
4. **Compensate flags must mean “mutation occurred,” not “path visited”** — idempotent hits that set `did*` true create false confidence and wrong release/consume behavior.
5. **Epic 5 risk is permission-safe consumption of Epic 4 reads, not missing event types** — assemblers, ledger, Approval metrics, and timeline badges exist; IDOR + PopulationPort + torn-read TOCTOU are the blockers to honest search/profile/dashboard.
