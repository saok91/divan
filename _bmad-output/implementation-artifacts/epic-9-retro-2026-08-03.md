## What went well

- **Epic 8 process encodes worked:** mandatory `selfcheck:design-qa`, first-touch EntityPicker / RowActionButton / FeedbackMessage, and amendment honesty were in Gate/Dev Notes from 9.1 onward — not rediscovered mid-epic.
- **Amendment → pass discipline held:** Bulk stayed `amendment` until 9.3 domain wiring was real; Reports structure passed in 9.5 without claiming charts; charts closed in 9.10; Settings never greened early.
- **Shared bulk substrate scaled:** one catalogue + one five-step shell + section-filtered templates avoided three divergent wizards.
- **Input-aware authorize (9.3):** retired the 9.1 `person.write` meta hardcode and unblocked non-person day-to-day templates without widening permissions.
- **IA host pattern reused:** thin route + section tabs + fat client workspace (9.4 → 9.5) kept chrome consistent.
- **8.7 rowActions deferral closed in 9.6:** outlined icon-only + stopPropagation + leave-guard honesty on the real events list; fixtures removed.
- **Drill-through as correctness surface (9.7):** shared `profileHref` / reconcile-href, anti-enumeration code→UUID redirect, and hydrate latch patches made deep links first-class.
- **No-dead-end gate (9.9):** permanent FR-59 regression lock; Settings absence correctly excluded from fail; placeholder quarantine.
- **Thin SVG chart chrome (9.10):** DESIGN tokens wired without Recharts/`react-is` debt; suppress ≠ empty ≠ zero honesty preserved.
- **Access honesty culture:** denied catalogue/report items show requirement rather than silent omit (9.1, 9.5, 9.8); capability error ≠ access-denied (9.7, 9.8).

- **9.3 domain cutover honesty:** PE `finalizeDraft` cannot nest inside migration cutover TX → prep / domain-outside / complete split; multi-row PE/HC absolute atomicity deferred with Honesty+harden messaging (must not claim “production unchanged” after partial side-effects).
- **Stale client / hydrate / cascade races (same class as Epic 8):** 9.2 orphan preview & file-input reset; 9.5 `runIntent` stale status; 9.6 `keepPreviousData` + snapshot token; 9.7 one-shot URL hydrate and timeline focus latch — review patch density highest on 9.6–9.7.
- **FeedbackMessage long-tail incomplete:** first-touch closed clones on rewritten panels; untouched ops/audit/list surfaces still carry raw `<p>` / StatusMessage debt (Epic 8 action still open).
- **Composed tRPC authorize / failure selfchecks deferred** across 9.2→9.3 — integration confidence gap remains.
- **Tooling friction:** recurring ESLint `eslint-module-utils` resolve failures; design-qa is the CI surrogate (no GitHub Actions workflow — honesty recorded in 9.9).
- **Production/security carry-ins untouched (by design):** PopulationPort, AD-6, SoD seed, list/mutation IDOR, Baseline projector, Vitest isolation, honesty-boundary doc — Epic 9 correctly stayed IA/operational-surface; LG-complete claims still blocked.

## Key insights

1. **Gate + first-touch beats another foundation epic** — Epic 8’s encode into 9.1 prevented clone debt on new surfaces; residual debt is almost entirely untouched panels, not new forks.
2. **Honesty+harden is a product posture, not only a review label** — 9.3’s atomicity deferral is acceptable only while fail messages and evidence counters tell the truth about side-effects.
3. **Deep-link hydrate is infrastructure** — 9.7 proved URL presets, one-shot latches, and team-narrowing honesty need shared kit before Settings deep-links multiply the same bugs.
4. **Shareable report URLs unlocked reconcile** — 9.5’s URL contract paid off in 9.7; Settings tabs should inherit the same “state in URL, not only in memory” habit.
5. **IA gates must exclude known future amendments** — 9.9’s Settings exemption prevented false red; Epic 10 must flip that once «تنظیمات» ships.
6. **Epic 8 follow-through was strong on process, weak on long-tail UX debt** — rowActions and design-qa closed; FeedbackMessage/typography/batched correction-audit lists and Epic 7 security opens still accumulate.
