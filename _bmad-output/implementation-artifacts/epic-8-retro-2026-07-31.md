## What went well

- **PO-approved epic closed Epic 7’s process risk:** Epic 8 was not invented from habit; PRD FR-57–FR-60 + epics + `ux-divan-2026-07-31` spines landed first.
- **Contract → primitive → retrofit → gate** scaled cleanly: 8.1 gap list mapped 8.2–8.10; 8.3 picker unlocked 8.4/8.5 without forks; 8.10 closed the “do not claim FR-58/LG-6 complete” deferral with evidence.
- **Identifier-first operator path shipped:** business code/name selection on event form and remaining UUID hotspots; Epic 4 mutation payloads unchanged and still green.
- **Real dead-click root cause fixed (8.7):** leave-guard silent-`false` paths now always surface dialog/reason — affordance alone would not have been enough.
- **Honesty culture held on UX completeness:** incomplete settings / bulk wizard / reports tabs recorded as **amendments** (8.10-A3), not fake mockup passes.
- **Runnable gate for Epic 9/10:** `pnpm --filter @divan/web selfcheck:design-qa` orchestrates prior selfchecks + matrix/checklist/probes; contrast failures forced DESIGN nudges (8.10-A1/A2) instead of silent green.
- **Story boundaries respected:** Dev Notes repeatedly said “8.x owns X; do not reopen Y,” reducing thrash across a dense same-calendar-day wave.
- **Gallery as shared lab:** `/dev/gallery` hosted layout, picker, feedback, and a11y spot-checks without polluting production routes.

## Challenges

- **Selfcheck vs reality:** Heuristics, allowlists, vacuous asserts, and false positives/negatives recurred (8.1, 8.2, 8.4, 8.7, 8.9, 8.10). Gate had to be patched to fail-closed on Gate/Results cells.
- **Cascade / hydrate / prefs races:** Highest density on 8.3–8.6 (Discard restore, inbound `?person=`, PA sync, prefs `anon` session, mode-switch stale ids).
- **Proof-set vs full migration:** Gallery and proof routes went green while long-tail panels still carry ad-hoc type, `StatusMessage` clones, blob skeletons, and incomplete `PendingSurface` adoption.
- **A11y completeness ceiling:** Combobox/focus restore, truncation AT, live-region stacking, tooltip-on-focus — review-driven patches every story; interactive keyboard DoD remains AST + gallery spot-check, not full production audit.
- **Presentation hydrate N+1:** Per-row `getById` / entitlement fan-out on correction + audit tables (8.5) — UX win with read-path cost.
- **Carry-in technical honesty debts untouched (by design):** AD-6, Baseline projector, PopulationPort, SoD seed, list IDOR, Vitest isolation — Epic 8 correctly stayed presentation-only, so production-completeness narrative still depends on those opens.

## Key insights

1. **UX spine alignment is layered, not binary** — Direction A proof surfaces (list, event form, dashboard, headcount) largely match `ux-divan-2026-07-31`; incomplete product surfaces are intentional Epic 9/10 amendments; residual hotspots (typography, FeedbackMessage, sticky thead) are honesty gaps inside the Epic 8 wave, not “later epic invent.”
2. **Fail-closed gates beat “file exists” oracles** — 8.10 review proved soft parsing is as dangerous as soft consumer hooks in Epic 7.
3. **Dead clicks are algorithm + affordance** — outlined icon buttons without leave-guard honesty would still feel broken.
4. **Mode/cascade/hydrate must clear dependents** — repeated stale-state class across pickers, prefs, and form snapshots; worth a shared kit pattern before Epic 9 bulk forms.
5. **Proof-set velocity is a trade** — it shipped the spine fast and overloaded 8.10/Epic 9 polish; Epic 9 should require first-touch adoption of shared primitives, not another deferred long tail.
6. **Epic 7 process lesson applied:** PO-approved scope prevented inventing an unplanned epic; unpaid multi-epic technical carry-ins still did not block UX delivery.
