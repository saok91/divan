- **AD-7 landed as three roles, one SoT discipline:** registry metadata ≠ store overrides ≠ resolver effective value; modules consume published API; guard selfcheck bans naked literals/env for registered keys.
- **Amendment → pass discipline held:** Settings stayed `amendment` through 10.1 (substrate only); 10.2 flipped functional surface and no-dead-end expectations together.
- **Custody RO honesty beat epic text:** 10.1 review forced `read_only_with_evidence`; 10.3 explicitly superseded epic editable wording — architecture honesty over backlog copy.
- **Validate-before-write closed warm-degrade loophole:** 10.3 shared `validateSettingsValue` so apply cannot hope the warm path will catch bad input.
- **FR51 closes unaudited override window:** trust assert + required `appendAccessEvent` in same TX; allow-path swallow-catch removed; trust suspend maps to INTERNAL ops copy, never AccessDenied.
- **Deep-link / hydrate kit reused:** path-segment settings tabs (10.2) and audit URL hydrate (10.5) inherited Epic 9 one-shot latch lessons — no silent coerce into another role’s domain.

- **Boundary non-widen proved:** `boundary-guard.selfcheck` in 10.5; wave-1 never widened permission/retention/export/audit boundaries.
- **Access honesty culture continued:** forbidden deep links → AccessDenied + audit; empty domains omitted from tablist; role-split tabs for hr vs system admin.

## Challenges

- **Fail-closed vs “looks OK” class persisted:** not-warmed resolve without degraded/ops ok (10.1); pool throw when `DATABASE_URL` missing (10.2); mutate while `storeUnavailable` (10.3); inventory binders lying about Infinity/0 and trust enforce (10.4); brief post-commit cache staleness after `skipCacheRefresh` (10.5).
- **Dual SoT / cutover drift:** correction-case env vs registry (10.1); identity session/provider_mode env → resolver (10.4); registry pool default 5 vs production effective 10; DISABLED inference cohort JSON-safe 0 vs runtime Infinity.
- **Soft-deny / access-event completeness:** missing `permission_set_missing` audit (10.2); export allow-event ordering before successful create (10.4); soft-deny remains best-effort while allow path is FR51-hard.
- **Process-local cache ceiling:** “no restart” is true per process only; multi-instance fan-out explicitly OOS — must stay documented, not silently upgraded.
- **UI state races on settings panels:** dirty draft wipe on sibling invalidate (10.3); sticky feedback across domain change (10.4); empty-filter flash before audit hydrate (10.5).
- **Selfcheck depth honesty:** inventory/export selfchecks mostly source-regex; 10.5 ephemeral DB gates skipped when Postgres unavailable (`ECONNREFUSED :5433`) — source + Manual DoD accepted, not live TX proof in that environment.
- **Production/security carry-ins untouched (by design):** SoD, list/mutation IDOR, AD-6 Prisma↔PoolClient, Baseline projector, PopulationPort, Vitest isolation, PE/HC absolute atomicity doc, FeedbackMessage long-tail on untouched panels, batched `lastChangedBy` identity DTOs — Epic 10 correctly stayed settings/AD-7; LG-complete claims still blocked.

## Key insights

1. **Encode-before-build compounds** — Epic 8→9→10 Gates carried design-qa, first-touch, and fail-closed contracts; Epic 10 velocity came from not re-litigating Settings ownership or registry shape.
2. **Epic text is not architecture** — custody editable in `epics.md` was wrong once review proved RO; supersession notes belong in the implementing story, not silent drift.
3. **Warm degrade ≠ write validation** — safety nets that protect reads must not become the apply path; reject-before-write is the operator contract.
4. **FR51 is a writer gate, not a log aspiration** — required append in the same TX is what prevents “config changed, audit missing.”
5. **Inventory can lie about posture** — binders that JSON-sanitize Infinity→0 or fail-open enforce→false invert security meaning; RO inventory needs the same fail-closed honesty as the resolver.
6. **Closing the product epic ≠ closing the honesty ledger** — Settings delivery does not close Epic 7–9 production/LG debts; provisional AR-\* numbers in inventory must not be misread as launch baselines.
7. **Roadmap end is a planning event** — with no Epic 11 in `epics.md`, next work is carry-in closure and/or new epic planning — not an implied continuation story.
